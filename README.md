# ⚽ Tablero Mundial 2026

Tablero interactivo del Mundial 2026 (México · EE. UU. · Canadá): fase de grupos, pronósticos con probabilidades, simulador de eliminatorias, favoritos al título, premios individuales y fichas por selección.

- **Página pública:** servida con GitHub Pages desde `index.html`
- **Actualización:** automática cada mañana (7:00) con resultados, estadísticas y noticias
- Datos: FIFA y prensa deportiva · Probabilidades: modelo propio · No es consejo de apuestas
